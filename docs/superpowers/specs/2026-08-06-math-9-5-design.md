# Calibration / threshold uncertainty package — design

> Privacy: historical filename retained for links. Internal quality ratings are private — see [docs/GRADING.md](../../GRADING.md). This doc describes metric/gate machinery only.

## Goal

Ship real metric/gate machinery for calibration honesty and threshold uncertainty (not a status-line bump). Synth labels remain a production-data gap, not a math-machinery gap.

## Package (calibration + uncertainty + bootstrap)

### Calibration honesty

1. **Brier score** on decision scores vs proven labels (promote path).
2. **Adaptive (quantile) ECE** alongside fixed-bin ECE; promote uses adaptive by default.
3. **Thin-slice fail-closed**: when `max_decision_ece` is set, ECE must be *usable* (`min_positives`, `min_bin_n` on occupied bins). Missing/unusable → gate fails.

### Threshold uncertainty

1. **Wilson score interval** on precision@soft (primary promote check).
2. Promote / `recommend_decision_thresholds.ok` requires Wilson lower bound ≥ `min_precision_at_soft` when that floor is set.

### Bootstrap (full package)

1. **Bootstrap CI** on precision@soft (secondary report + optional gate via `require_precision_bootstrap_ci`).
2. Default: report always; gate on Wilson. OP may set `require_precision_bootstrap_ci: true` to also require bootstrap lo ≥ floor.

## Config (`monitoring` / `head_thresholds`)

| Key | Default | Role |
|---|---|---|
| `ece_binning` | `adaptive` | `fixed` \| `adaptive` |
| `min_ece_positives` | `5` | usable ECE |
| `min_ece_bin_n` | `3` | occupied-bin mass |
| `max_decision_brier` | `0.25` | promote ceiling |
| `precision_bootstrap_n` | `400` | bootstrap draws |
| `require_precision_bootstrap_ci` | `false` | optional gate |

## Non-goals

- Live chargeback volume / isotonic per market (Downstream / live data path).
- Changing tier ladder semantics.

## Success

- Invariant tests for Brier, adaptive ECE usability, Wilson/bootstrap CI, promote fail-closed.
- Promote path uses the new gates when monitoring floors are set.
